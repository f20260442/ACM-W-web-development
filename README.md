# To-Do List
A web application built with HTML, CSS, and JavaScript.

## Pages & Navigation
- index.html: A menu page of sorts, introducing the web apps features as well as connecting it to the to do list page
- app.html: The To-Do List App with local storage.

## Key Features
- Task CRUD: Add, check off (complete), edit existing task text, and delete tasks.
- Priority Badges: Color-coded borders for Low (Green), Medium (Amber), and High (Red) urgency items.
- Due Dates: Attach specific dates to your tasks.
- Drag & Drop Reordering: Drag tasks to re-arrange their order dynamically.
- Progress Bar: Live progress bar and task count ("X of Y tasks done").
- Clear Finished Tasks: One-click cleanup button for completed items.
- Local Storage: Tasks remain saved in your browser via `localStorage`.
